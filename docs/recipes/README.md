# 실행 예제 (recipes)

기능 하나를 처음부터 끝까지 돌려 보는 짧은 예제입니다. 각 예제는 설명 몇 줄과 그대로 실행되는 코드로 되어 있습니다. 모든 예제는 `--fake`(또는 `FakeLane`)로 모델 없이 먼저 돌려 볼 수 있습니다.

무엇을 넣어야 대화가 잘 나오는지(사실·카드·시민 구성)는 [지식 베이스 만들기](../knowledge-base)에서 다룹니다.

|---|---|

| [연애 예능 시청자 단톡방](dating-show-viewers.md) | 여러 갈래 예측이 맞서는 주제를 지식 베이스 폴더로 실행 (README 데모 화면의 원본) |
| [공개 데이터셋으로 시민 뽑기](nemotron-personas.md) | Nemotron-Personas-Korea 증강판에서 시민을 읽어 방 만들기 |
| [모델 두 개로 나눠 말하기](two-model-lanes.md) | 앵커 레인(큰 모델)과 기본 레인(빠른 모델) 설정 |
