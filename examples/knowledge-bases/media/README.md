# 미디어 — 웹툰 '달빛 정류장' 드라마화와 결말 각색 (가상)

'달빛 정류장'은 이 예시를 위해 지어낸 작품입니다. 콘텐츠 소식처럼 팬층에 따라 반응이 갈리고, 공식 발표·보도·소문이 섞이는 경우를 보여 줍니다.

## 구성

| 항목 | 내용 | 이유 |
|---|---|---|
| 상태 어휘 | `statuses`: 공식 확인 / 보도 / 루머 / 지난 사례 | 제작사 공식 입장과 매체 보도, 커뮤니티 소문을 구분 |
| 주제 문구 | `generic`, 머리표 `[콘텐츠 소식]`, 관계 칸 `[이 작품과 나]` | |
| 방 장면 | 드라마 수다방 | |
| 사실 8개 | 공개 시기·캐스팅·작가 참여(공식), 결말 각색(보도), 조연 교체(루머) | 같은 목록 안에서 확실성이 다른 정보를 시민이 구분해 말하는지 보기 위해 |
| 카드 8장 | 결말 각색, 캐스팅 어울림, 새 시청자 진입, 작가 참여, 구독 부담 등 | 원작 팬 / 일반 시청자 / 출연자 팬 |
| 상황 태그 | `original_fan`, `casual_viewer`, `actor_fan` | 결말 각색 카드는 원작 팬에게, 배우 팬 카드는 배우 팬에게 |
| 시민 속성 | 원작을 본 정도, 구독 중인 서비스, 좋아하는 배우 | `relation`·`living`·`values` 칸 |

## 이 도메인에서 주의할 점

- 실존 인물(배우, 출연자)을 다루는 시뮬레이션은 그 사람에 대한 근거 없는 추측을 만들어 낼 수 있습니다. 예시처럼 가상의 작품·인물로 구성하는 것을 권합니다. 실존 작품을 다룰 때도 사실 목록은 공식 발표와 보도 내용으로 한정합니다.
- 가벼운 찬성 말투(`light_support`)가 각색 논란 얘기에 어색하게 붙을 수 있습니다. 대응은 [05](../../docs/05-topic-and-spec.md) 참고.
