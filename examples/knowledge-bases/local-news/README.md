# 동네 소식 — 공영주차장 야간 유료화 (가상)

이해관계가 갈리는 동네 소식의 예시입니다. 같은 소식이 밤에 차를 대는 주민에게는 비용이고, 차 없는 주민에게는 골목 정리이며, 가게 주인에게는 손님 문제입니다.

## 구성

| 항목 | 내용 | 이유 |
|---|---|---|
| 주제 문구 | `generic`, 머리표 `[동네 소식]` | 정책 문구(`policy`)는 "정부 정책" 말투가 강해 동네 공지에 어색함 |
| `common_words` | 주차, 주차장, 요금, 야간, 유료 | 누구나 쓰는 낱말이 "이미 많이 나온 말"로 안내되지 않게 |
| 사실 8개 | 확정 4 · 과거 실적 1 · 계획 2 · 검토 1 | 확정과 계획을 섞어 두어 시민이 구분해 말하는지 볼 수 있게 |
| 카드 8장 | 찬성 2 · 반대 3 · 조건부 2 · 중립 1, 관점 4종 | 이용 주민 / 차 없는 주민 / 상인 / 어르신 |
| 상황 태그 | `resident`, `car_owner`, `shop_owner` | `car_owner`가 필요한 카드(야간 귀가 주차, 자리 찾기)는 차 있는 시민에게만 |
| 전제(premises) | 옆 동네 골목 주차 증가, 장기 방치 차량 | `[들은 얘기]`로 추측형 출처 말투를 확인하는 용도 |
| 시민 8명 | 대상 당사자 점수 3, 이웃 2, 간접 1 | 세탁소 주인(`공덕`)은 `affected: false`로 사실을 앞 4개만 봄 |

## 실행

```bash
python -m kb_tools.validate domains/local-news
python -m kb_tools.run domains/local-news --fake --msgs 12
python -m kb_tools.run domains/local-news --msgs 40
```

## 실제 모델로 돌렸을 때 본 것 (A.X, 20메시지 1회)

- 대화가 "정기권 40장"으로 몰렸습니다. 이 화제는 카드 1장(야간 귀가 주차)과 사실 1개에서 나왔는데, 구체적인 숫자가 있어서 다른 시민들도 받아 말했습니다. 이번 실행에서는 숫자가 들어간 사실이 대화를 끌어당겼습니다.
- 사실과 다른 시간("새벽 5시")이 한 번 나왔습니다. 사실 목록에는 "오전 7시"로 적혀 있습니다.
- 옆 동네 사례는 "옆 동네 얘기 들어보니까 \~하더라고요, 어떻게 될지 모르겠어요"처럼 들은 얘기 말투로 나왔습니다.
