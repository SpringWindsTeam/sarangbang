# 회사 공지 — 사내 주 4.5일제 시범 운영 (가상)

같은 공지가 부서에 따라 혜택이 되기도 하고 형평성 문제가 되기도 하는 경우입니다.

## 구성

| 항목 | 내용 | 이유 |
|---|---|---|
| 주제 문구 | `generic`, 머리표 `[회사 공지]`, 관계 칸 `[이 공지와 나]` | |
| 방 이름 | 입사 동기방 | 서로 다른 부서 사람들이 한 방에 있는 장면 |
| 사실 8개 | 대상 부서, 급여, 제외 부서와 보완책, 이후 검토 | 확정(시범 내용)과 검토(전사 확대)를 구분 |
| 카드 8장 | 제외 부서 형평성, 업무 몰림, 가족 시간, 협업 공백 등 | 시범 부서와 제외 부서 카드가 따로 있음 |
| 상황 태그 | `pilot_team`, `excluded_team`, `parent` | 형평성 카드는 제외 부서에게만, 업무 몰림 카드는 시범 부서에게만 |
| 시민 7명 | 시범 부서 3, 제외 부서 4 | 제외 부서가 소수가 되지 않게 |

## 이 도메인에서 주의할 점

- 회사 내부 정보는 공개 자료가 없어 카드를 사내 의견 게시판이나 설문 응답으로 만들게 됩니다. 응답자를 특정할 수 있는 표현은 카드에 남기지 않습니다.
