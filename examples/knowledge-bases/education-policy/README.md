# 교육정책 — 초등 돌봄 운영 시간 연장 (가상)

정책 사양(`ko_s12`)과 정책 주제 문구(`policy`)를 쓰는 예시입니다. `ko_s12`는 한국어 교육정책 시뮬레이션에서 비교 시험으로 고른 사양입니다.

## 구성

| 항목 | 내용 | 이유 |
|---|---|---|
| 주제 문구·사양 | `policy` + `ko_s12` | 정책 소식에 맞춰 시험된 조합 |
| 사실 8개 | 계획 5 · 과거 실적 2 · 검토 1 | 아직 시행 전인 정책. "이미 시행 중"으로 말하는지 볼 수 있게 |
| 카드 8장 | 맞벌이 퇴근 시간, 아이 피로, 저녁 인력 안전, 교직원 부담 등 | 학부모 / 교직원 / 자녀 없는 납세자 관점 |
| 출처 | 교직원 부담 카드는 `kind: 단체 성명` | `[들은 얘기]`에서 "어느 단체 성명"으로 표시됨 |
| 상황 태그 | `parent_young`(대상 학년 자녀), `school_staff` | 학부모 카드는 대상 학년 자녀가 있는 시민에게만 |
| 자녀 정보 | `kids`에 학년까지 | 자녀 학년과 대상 여부가 있어야 처지를 지어내지 않음 |
| 관계 문장 | "작은딸은 대상이고 큰딸은 3학년이라 대상이 아니다" | 대상 여부를 사실로 적어 줌 |

## 이 도메인에서 주의할 점

- 실제 정책을 다룰 때는 발표 원문에서 `kb_tools.extract_digest`로 사실을 뽑고, 상태(계획·확정)를 원문과 대조합니다. 정책 발표는 "추진", "예정" 같은 말이 많아 계획과 확정이 섞이기 쉽습니다.
- 정책 소식은 기사 한 편의 시각이 대화 전체를 끌고 가기 쉽습니다. 카드는 기사가 아니라 학부모 커뮤니티, 교원 게시판, 블로그 후기에서 고르게 모읍니다.
