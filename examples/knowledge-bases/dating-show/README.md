# 연애 예능 한 회 — 상철과 영숙은 잘될까 (가상)

README 맨 위 데모 화면의 원본 지식 베이스입니다. 방송 내용은 모두 지어낸 것이고, 출연자 이름은 연애 예능에서 흔히 쓰는 가명입니다.

찬반이 아니라 **여러 갈래의 예측이 맞서는 주제**를 보여 줍니다. "상철·영숙 찐사", "영숙은 영호행", "옥순 변수", "최종 0쌍"처럼 시청자마다 다른 이론을 갖고 있습니다.

## 구성

| 항목 | 내용 | 이유 |
|---|---|---|
| 상태 어휘 | `statuses`: 방송 내용 / 예고편 / 지난 회 | 본방에서 확인된 장면과 예고편 장면을 구분 |
| 사실 9개 | 데이트 선택, 출연자 발언, 예고편 장면 | 해석이 갈릴 만한 장면을 사실로 |
| 카드 7장 | 커플 이론별 한 장씩 | 이론이 서로 다른 시민에게 배분되도록 |
| 시민 7명 | `relation`에 각자의 예측("영숙은 결국 영호를 고를 거라고 본다") | 예측을 입장 문장이 아니라 **사실 칸**으로 준다 |
| 입장(`lean`) | 전원 비움 | 입장 기울기는 찬성↔반대 한 축이라 여러 갈래 예측을 담지 못함 |
| `common_words` | 출연자 이름, 방송, 데이트 | 이름이 "이미 많이 나온 말"로 안내되지 않게 |

입장 기울기 대신 사실 칸으로 예측을 주는 방식은 [01 원칙 3 — 지시보다 재료](../../../docs/knowledge-base/01-knowledge-base.md#3-지시보다-재료를-준다)를 그대로 따른 것입니다.

## 실행

```bash
cd examples
python -m kb_tools.run knowledge-bases/dating-show --msgs 24
```
