# 신제품 출시 — 접이식 스마트폰 '누리폰 폴드 3' (가상)

'누리'와 '누리폰'은 이 예시를 위해 지어낸 회사·제품입니다. 신제품 출시처럼 확인된 정보와 소문이 섞이기 쉬운 소식을 보여 줍니다.

## 구성

| 항목 | 내용 | 이유 |
|---|---|---|
| 상태 어휘 | `statuses`: 공식 발표 / 출시 예정 / 유출·루머 / 이전 모델 | 정책 어휘(확정·시행 등) 대신 제품 소식에 맞는 확실성 단계 |
| 주제 문구 | `generic`, 머리표 `[신제품 소식]`, 관계 칸 `[이 제품과 나]` | |
| 방 장면 | 고등학교 동창방(`room_name`, `room_desc`) | 기기 얘기를 편하게 나누는 사이 |
| 사실 8개 | 출시일·가격·무게·사전 예약·보상 판매 + 이전 모델 문제 이력 | 장점과 걱정거리가 둘 다 사실에 있게 |
| 카드 8장 | 가격, 내구성, 무게, 보상 판매, 갈아타기, 큰 화면 쓰임새 등 | 기존 사용자 / 경쟁 제품 사용자 / 구매를 미루는 사람 |
| 상황 태그 | `current_user`, `rival_user` | 보상 판매·무게 카드는 기존 사용자에게, 갈아타기 카드는 경쟁 제품 사용자에게 |
| 시민 속성 | 쓰는 폰, 할부 상태, 구매 기준 | `relation`·`living`·`values` 칸에 제품 관련 사실을 넣음([04](../../docs/04-personas.md)) |
| 휴대폰 매장 주인(`성호`) | 상황 태그 없음 | 사는 사람이 아닌 파는 사람의 관점 |

## 이 도메인에서 주의할 점

- 실제 제품을 다루면 모델이 원래 알던 사양·가격을 섞어 말할 수 있습니다. 대화에 나올 사양·가격·출시일은 사실 목록에 빠짐없이 넣습니다.
- 유출·루머는 상태를 구분해 넣거나, 카드의 `premises`(들은 얘기)로 넣어 추측형으로만 나오게 합니다.
- 리뷰·커뮤니티 글에는 협찬 글이 섞여 있어 찬성 카드가 부풀기 쉽습니다. 협찬 표시가 있는 글은 수집에서 뺍니다.
