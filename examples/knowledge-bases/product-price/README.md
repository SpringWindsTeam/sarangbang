# 제품 — 음악 구독 서비스 요금 인상 (가상)

'하루뮤직'은 이 예시를 위해 지어낸 서비스입니다. 제품·서비스 소식에서 이용자 유형별로 관심사가 갈리는 경우를 보여 줍니다.

## 구성

| 항목 | 내용 | 이유 |
|---|---|---|
| 주제 문구 | `generic`, 머리표 `[서비스 소식]`, 관계 칸 `[이 서비스와 나]` | 소식 종류에 맞는 머리표 |
| 방 이름 | 대학 동기방 | `room_name`으로 단톡방 장면을 바꿈. 시민 나이대(20대 후반)와 맞춤 |
| 사실 8개 | 요금별 인상 폭, 기존 이용자 유예, 함께 바뀌는 혜택 | 인상과 혜택을 함께 넣어 한쪽 얘기만 나오지 않게 |
| 카드 8장 | 가족 요금 분담, 다른 서비스로 이동, 고음질, 학생 요금 등 | 이용자 유형(개인 / 가족 요금제 / 학생 / 창작자)별 관심사 |
| 상황 태그 | `subscriber`, `family_plan`, `student` | 가족 요금 분담 카드는 `family_plan`인 시민에게만 |
| 바깥 정보 | "다른 서비스는 석 달 무료"를 카드 전제로 | 경쟁 서비스 정보는 사실 목록이 아니라 들은 얘기로 둠 |
| 시민 7명 | 무료 이용자(`준호`)는 `affected: false` | 소식의 대상이 아닌 사람도 대화에 섞이게 |

## 이 도메인에서 주의할 점

- 실제 서비스 이름을 쓰면 모델이 원래 알던 정보(실제 요금, 실제 경쟁사)를 섞어 말할 수 있습니다. 실제 서비스를 다룰 때는 요금·혜택을 사실 목록에 빠짐없이 넣습니다.
